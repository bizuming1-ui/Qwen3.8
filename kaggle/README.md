# Kaggle-compatible workspace

| Kaggle path | Repository path | Git policy |
| --- | --- | --- |
| `/kaggle/working` | `kaggle/working` | Source and notebooks are tracked; generated artifacts are ignored |
| `/kaggle/input` | `kaggle/input` | Local-only by default |

Open the browser workbench to import, edit, execute, save, and synchronize code. This is a lightweight Kaggle-style environment, not a hosted Kaggle service: installed packages and available accelerators depend on the machine running it.
